# Reproduce Null Hypothesis

Checked from a clean clone on 31 Oct 2026: tests, demo and the frozen-results verifier all run with no API keys and no network.

## 1. Offline: no keys, no network (about 1 minute)

```bash
git clone https://github.com/karunprem45/null-hypothesis.git && cd null-hypothesis
make setup                                   # venv + dependencies (needs pip access once)
make test                                    # 40 pass; 8 skip until data/ is built (they say why)
make demo GENE=Gene_01                       # replays one gene's frozen board round by round
.venv/bin/python -m exploratory.scripts.verify_frozen
```

`verify_frozen` checks, with nothing but the repo:

1. every SHA-256 in `frozen_results/SHA256SUMS` (63 files),
2. the AUROC of all 12 arms in `frozen_results/arms_table.md`, recomputed from the frozen score files,
3. the A3 round-0 ablation, re-scored from the frozen A3 boards with the unchanged `scoring.py` (difference 0).

Labels come from `reproduce/panel_labels.csv`, published after `results-final` so a clean clone can recompute the table. Blindness only mattered while the arms ran; the agents never had access to this file.

The exploratory analyses also run offline from frozen outputs:

```bash
.venv/bin/python -m exploratory.scripts.acvr1c_case    # needs data/ for the blindness check
.venv/bin/python -m exploratory.scripts.secondary      # secondary contrasts, A2 section if present
```

## 2. Network, no keys: rebuild the evidence (about 5 minutes)

```bash
make data panel        # Open Targets 26.09 + Ensembl; builds data/, the blind panel and views, runs isolation tests
make test              # now all tests run, including the 203 isolation checks
make baselines         # S1-S4
```

Open Targets publishes new releases; a later release can change the pool. The frozen results were built from 26.09.

## 3. Keys needed: rerun the LLM arms

| Step | Needs | Command |
| --- | --- | --- |
| A1, A3 (pre-registered) | Vertex AI sign-in: `gcloud auth application-default login` | `make allarms ablations report` |
| A3 + Evo 2 (extension) | `NVIDIA_API_KEY` (build.nvidia.com) | `make explore` |
| gpt-5-mini runs (extension) | `OPENAI_API_KEY` | `make explore` |
| A2 centralized (extension) | Vertex AI sign-in | `.venv/bin/python -m exploratory.A2.run_a2` |

Keys go in `.env` (see `.env.example`); `.env` and `data/` are gitignored. Reruns of LLM arms will not reproduce scores exactly: Gemini at temperature 0 still varies between runs (A2 re-ran the round-0 configuration and 23 of 40 genes got identical scores). The frozen scores are the record.

## What never changes

`frozen/` and `frozen_results/` are not regenerated by any command above except `make freeze-results`, which a reproduction should not run.
